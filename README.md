## 这次升级了什么

这个 Skill 现在不只是“白底处理器”，而是一整套 **3D 打印产品封面工作流**。

你可以把它理解成：

- 第 1 步：实拍图 → 白底高级棚拍封面
- 第 2 步：白底封面 → 标题封面图
- 第 3 步：白底封面 → 场景图 / 穿戴图
- 第 4 步：白底封面 → 细节展示图 / 装配图 / 背针图

也就是说，它既能做“封面基础处理”，也能继续往下生成一整套展示图。

## 默认能力

### 1）封面基础处理

- 保留模型原本的造型、颜色、结构和装配关系
- 不随意改动主体
- 背景统一成纯白色
- 优化成更干净的高级棚拍实物质感
- 保留真实材质、3D 打印层纹和自然落地阴影
- 光线柔和且有方向感
- 默认比例为 4:3
- 多张图片会逐张单独处理，不自动拼图

### 2）可扩展输出

在完成白底封面后，还可以继续生成：

- **标题封面图**：适合发平台首页、作品封面、海报缩略图
- **场景图 / 穿戴图**：适合胸针、摆件、收纳件、桌面产品等展示使用效果
- **细节展示图**：适合展示零件、结构、装配方式、安全别针、背面结构等

## 常用触发语句

### 只做白底封面

- 按封面处理这几张图片
- 按封面处理
- 做封面
- 优化成封面图

### 白底封面 + 后续衍生

- 按封面处理，并生成标题图
- 先按封面处理，再做场景图
- 按封面流程处理这组图
- 做一套图：白底封面、标题图、穿戴图、细节图

### 直接做某一类图

- 生成标题图，标题是“猫耳马蹄莲胸针”
- 继续生成胸针穿戴图，现代温柔一点
- 再做一张细节展示图，把零件和背针展示清楚

## 适合的产品类型

- 3D 打印模型
- 手作产品
- 小摆件
- 胸针 / 饰品
- 收纳件
- 文创类产品
- 需要做作品展示封面的实拍图

## 使用建议

### 最稳的用法

1. 先上传原始实拍图
2. 说：**按封面处理这几张图片**
3. 白底图出来后，再继续说：
   - **继续生成标题图，标题是……**
   - **继续生成穿戴图 / 场景图**
   - **继续生成细节展示图**

### 一句话连着做

也可以直接说：

> 按封面流程处理这组图，先做白底封面，再生成标题图、穿戴图和细节图。

## 默认风格倾向

### 白底封面

- 纯白背景
- 高级棚拍实物质感
- 柔和方向光
- 自然落地阴影
- 构图干净简洁

### 标题图

- 以产品为主角
- 标题大且清晰
- 可爱或产品适配的字体风格
- 必要时可加色块辅助
- 适合平台封面传播

### 穿戴图 / 场景图

- 优先真实自然
- 主体保持不乱改
- 对胸针类产品，默认偏 **现代、温柔、家常一点的服装**
- 背景不过分花哨，不要明显舞台灯光

### 细节展示图

- 适合展示零件、结构、装配方式
- 画面清爽
- 重点清晰
- 适合做产品说明和详情页素材
